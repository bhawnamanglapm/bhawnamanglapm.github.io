Travel Support AI Copilot — Interactive Demo

Try the flows this design scopes: cancel a booking, ask about baggage, change a date, or trigger an escalation. Watch the intent classification, confirmation gate, and audit log respond in real time.

What this actually is: a rule-based simulation running entirely in your browser — keyword matching stands in for intent classification, and the "tool calls" return fixed illustrative numbers, not a live booking system. A public static site can't safely hold an API key to call a real LLM (anyone could copy it from page source), so this demonstrates the architecture and guardrails from the full case study (T5) — the confirmation gate, the escalation handoff, the audit trail — working end to end, not a claim that this is production-grade language understanding.
